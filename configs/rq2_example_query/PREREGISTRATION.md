# Example selection

Use the GMMFormerV2 ActivityNet seed-9527 test scores, original ER cutpoints, frame Ward-8, fp32 fusion 0.7*clip+0.3*frame, original query IDs and official captions. The primary eligible set consists of positives in Q1 with original rank 2–100 and improved rank after compressing all videos (F). Choose a query whose number of ranks gained is the exact sample median among eligible queries. Break ties by smallest original rank then lexicographically smallest original query ID. For the mirror example use Q4 positives with original rank 1–100 and strictly worse F rank, then use the same rule on ranks lost. For an even count use the arithmetic mean of the middle two. If no query equals the median, stop and report that the rule has no solution. Never choose a nearest value or replace an example based on scores or interpretation.

Read O (positive-only) and C (competitors-only) ranks from the original analysis. For the two selected queries use original CPU torch.argsort(-scores, stable=False) and verify original and F ranks against their stored values. In the primary example count videos that move from ahead of the positive to behind it; reverse this definition for the mirror. Exclude the positive, report opposite-direction crossings, quartile distribution and all crossing video entries. Show at most five by descending original fusion score, then lexicographic video ID. For each full eligible population before median/tie selection report counts and fractions: primary, F's positive score decreases and its rank improves; mirror, the same score decreases and its rank worsens. Both report the fraction with worse O and better C ranks. Strict changes exclude ties. Compute descriptive fractions without additional filtering or intervals.
