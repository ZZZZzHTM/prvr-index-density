# Frame compression rules across models

This optional analysis follows the other prespecified checks. Use the retrained DreamPRVR model and the released HLFormer model on Charades, ActivityNet and TVR. Keep the checkpoint, clip branch, scorer and native fusion weights fixed. Compress the valid encoded frame outputs once per video to at most eight representatives, without re-encoding frames. If a required original implementation or input cannot be used, report the missing item and skip it without substituting an algorithm.

Compare the original cosine-input Ward, uniform temporal pooling and k-means implementations. Reuse the Ward scores from the cross-model quartile analysis. Uniform pooling uses valid-length windows with boundaries parameterized by k and k+1. Keep the original vectors for short videos. For k-means at k=8, preserve the original valid outputs when L<=8. Otherwise cluster the raw valid outputs using Euclidean distances, promoting fp32 vectors to fp64 and centering them for numerical stability. Use k-means++ with one probability-weighted candidate per center, 10 initializations, a 300-iteration limit, tolerance 0.0001 and random seed 20261023 reset for each video. An empty cluster takes the farthest residual point from a cluster with multiple members, breaking ties by original order. Stop on unchanged repaired assignments or summed squared center shifts no greater than the tolerance times mean coordinate population variance. Select the lowest final nearest-center squared error in fp64; on an exact tie take the earliest initialization. Cast centers to fp32 for native scoring.

For both models, score only valid centers using the original maximum normalized dot product and retain the original clip scores. Use paired positive-video bootstrap intervals within each model/dataset cell: 2,000 draws, default_rng(20261023), shared across rules and linear .025/.975 quantiles. Report all three compressed-minus-uncompressed SumR differences with intervals for each cell and rank the methods by the equal-weight mean of the three dataset differences for each model. Report all results in the supplement. Mention the ordering in the main text only when Ward has the smallest mean loss on both models.
