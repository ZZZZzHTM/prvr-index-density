# Adaptive frame budgets

Before retrieval evaluation, test confounding by valid frame count L across all 20 cells (three GMMFormerV2 seed 9527 runs, three DreamPRVR seed 0 runs, 14 released checkpoints). Reuse the original encodings, masks, queries and scores. Use four CPU threads, one inter-op thread, no training or encoding. Compute partial Spearman correlation between effective rank (ER) and the change in positive fusion rank by regressing average ranks on rank(L) with an intercept and taking Pearson correlation of the residuals. Constant L reduces to ordinary Spearman. Report ordinary Spearman and frame-only partial correlation. Resample videos 2,000 times, rerank all three variables and recompute residuals in each draw. Use NumPy default_rng(20261023), linear 2.5th and 97.5th percentiles, and record undefined draws. Stratify L into <32, [32,64), [64,128), and >=128. Within each stratum use linear ER quartiles and searchsorted(side="left"), retaining ties and marking empty groups missing. Report group video and query counts, original and Ward-8 SumR and loss against the full test corpus. Freeze all allocation rules before observing retrieval scores.

Frame-only budgets B are 4, 8 and 16. ER is the entropy effective rank of the singular values of the row-normalized valid frame outputs. R0 uses k=B. R1 uses k=clip(rint(alpha*ER),1,min(L,32)). R2 cuts all trees at a common distance tau and caps the number via maxclust=min(L,32) if necessary, with at least one cluster. R3 replaces ER in R1 with L and scale beta. For R0/R1/R3, if L<=k keep every original vector. Otherwise use maxclust k. Normalize valid rows in float64, clip 1-cos to [0,2], symmetrize and zero the diagonal, use SciPy Ward linkage without optimal ordering, and average unnormalized rows in each cluster in float32. Tied merge heights may give fewer centers; never fill missing clusters. Use the original scorer.

For R1/R3 solve for the largest feasible lower endpoint by bisection on nominal total k <= B times corpus size. Start at zero and max(1,2*max(min(L,32)/feature)); stop after 80 iterations or when floating-point endpoints stop changing. NumPy rounds ties to even. Report actual and nominal means independently. For R2 start one floating-point value below the lowest height and at the highest height and return the smallest feasible upper endpoint using actual counts. Set tau=0 if all videos have one frame. Return the saturated allocation when its budget already fits. Report any unattainable budget shortfall; every actual mean must be <=B. Allocate only from frames, L, ER and trees before opening queries, grades or scores. Reuse identical partitions and verified Ward-8/Ward-16 score caches.

Use original fusion weights (GMMFormerV2 0.7/0.3, reproduced DreamPRVR 0.6/0.4 on Charades and ActivityNet and 0.5/0.5 on TVR, otherwise official weights). MS-SL uses attention guided by its key clip, recomputing only the key-clip argmax if absent; SDM uses original slot scoring and other cases use original maximum cosine. Require R0/B=8 ranks to match the original per query. Report R@1/5/10/100, SumR, differences against uncompressed and same-budget R0, mean nominal/actual k, counts and five-number summaries. Add 528 fixed clip entries for MS-SL and 32 for other models when reporting the total index. For each B compare R1/R2/R3 with R0 and uncompressed using the same 2,000 paired positive-video cluster draws, the same seed and linear percentiles, retaining query multiplicities. Keep allocations fixed, reset draws by cell, and apply no multiplicity correction. For B=8 report R0/R1/R3 GMMFormerV2 loss in ER quartiles. For each B count improvements, ties and declines against R0 using unrounded hit counts and average delta SumR with equal weights across 20 cells.
